CLAUDE CODE のスキル棚卸し

スキル棚卸し 2026年10月

どの作業でどのスキルを使うかの早見表と、重なっているスキル、支えが足りない作業、自作スキルの点検結果をまとめました。

調査日：2026-10-27 対象：このPC（kkmac）の有効なプラグインと dotfiles の自作スキル 使用実績：過去120日の152セッション

結論

  • いちばんの問題
    重なりよりも、スキルが見えなくなっていることが問題です。Claude Code がスキルの説明文に使える量には上限（モデルが一度に読める量の1%）があり、超えると使われていないものから順に説明文が消えて、名前だけになります。いまは約450個のうち、説明文が残っているのは40個ほどです。自作スキルの多くは名前だけになっていて、名前で呼ばない限り自動では選ばれません。
  • 重なり
    調べもの、コードレビュー、計画、スライド、ブラウザ操作で、同じ目的のスキルが4〜6個ずつ並んでいます。多くは ecc の中のスキルと、他のプラグインや自作スキルとの重なりです。
  • 足りない
    いちばん多い作業の iOS アプリ開発で、後半の工程（課金、App Store への提出と審査、実機での確認）を支えるスキルがありません。繰り返している市場調査にも決まった型がありません。
  • 自作スキル
    37個のうち、このPCで使われたのは4個です。研究・機械学習の実験向けの sdd 系6個のうち4個は、2月から更新されていません。archify と archify-review はリンク切れで、読み込まれていません。

研究・論文の作業は、もう1台のPC（kkmclab）が中心です。このPCの記録には研究の作業がほとんどないので、研究系スキルの「使用0回」は少なめに出ている可能性があります。説明文の上限の仕組みは、Claude Code の公式説明（Skills の「Skill descriptions are cut short」）で確かめました。

支えが足りない作業

iOS アプリの課金・提出・審査

10月23日に「課金で解放するはずの機能が未実装のままだった」という確認がありました。課金（StoreKit）、App Store の審査の決まり、TestFlight、App Store での見つけやすさ（ASO）を扱うスキルはありません。

候補：プラグイン一覧の apple-skills（App Store・ASO・テストなど164個のスキルを23の分類にまとめたもの）、Mobile App Design (iOS)（課金画面や初回案内の設計）。どちらも第三者製で、中身はまだ確かめていません。

市場調査の決まった型

Second Brain に、10月だけで市場調査のノートが4件あります（小遣いを稼げる iOS アプリの候補、推し語りの市場など）。毎回、観点と出典の選び方を一から決めています。

案：観点（市場規模、競合、価格、作る手間）と保存先（Second Brain）を決めた自作スキルにする。ecc:market-research を土台にできます。

実機・シミュレータでの確認

iPhone Duo の画面や、iPhone と Mac の同期など、動かして確かめる依頼が続いています。組み込みの run スキルでアプリを起動できますが、iOS のシミュレータ向けの手順はありません。

案：上の apple-skills を試し、足りなければ xcodebuild とシミュレータの手順を自作スキルにする。

メールと予定（gog）

CLAUDE.md の道具の一覧に gog CLI（Gmail・カレンダー・Drive）がありますが、使い方を書いたスキルがありません。秘書の役割を頼むたびに、使い方を調べ直すことになります。

案：よく使う命令と、送信前に確認する決まりだけを書いた短いスキルを作る。送信を伴うので、手動で呼ぶ設定（disable-model-invocation）にします。

足りている作業

資格試験の学習は、study-memory プロジェクトの中の study-quiz で足りています。論文・文献・研究方法は、むしろスキルが多すぎる状態です。

次にやること（効く順）

  1. 説明文の枠を空ける。ecc の295個のうち、使わない言語や分野（Java、Kotlin、PHP、Laravel、Django、ネットワーク機器、物流、金融など）を skillOverrides で "off" にします。先に /skill-doctor で、スキルごとの枠の使用量と使用回数を測ってから決めます。
  2. リンク切れを直す。archify と archify-review のリンク先を ~/.agents/skills に直すか、使わないなら消します。
  3. iOS の後半の工程を補う。apple-skills を試し、課金・提出・審査が足りるかを確かめます。
  4. 自作スキルを整理する。sdd 系の入口を1本にまとめ、休止候補は研究のPCで使っているかを確かめてから休止します。英語だけの説明文には、日本語の依頼の言葉を先頭に足します。
  5. 型が決まっている作業をスキルにする。市場調査と gog（メール・予定）の2つです。
