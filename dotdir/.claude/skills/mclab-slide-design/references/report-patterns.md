# 報告の型（自治体向け・社内向け）

題だけを並べた筋書きを作るときに、相手に合う型を選ぶ。ページの数は内容で増減してよい。どちらの型でも、題は主張を名詞か数値で止める（SKILL.md「中身の組み立て」）。

## 自治体向けの報告

自治体の担当者に、事業の結果を報告し、次年度の継続や協力を相談する資料。分析の報告で終わらせず、相手の目的に対して何が分かったか、次に何をお願いしたいかまで書く。2026年11月、Claude が作った分析中心の資料を担当者が手直しした差分（1件）から作った。

実施目的、まとめの判断、お願いとご相談の中身、他地域の実績は、データからは作れない。作る前に依頼者に聞き、答えが無ければ「【要記入】」だけを置いたページにする。Claude が中身を創作しない。

### ページの並び

| 順 | ページ | 書くこと |
|---|---|---|
| 1 | 表紙 | 「【報告】〇〇町 〇〇と〇〇の結果」。対象（期間・計測会・人）と、実施目的を (1)(2) の番号で書く。右下に日付・会社名・部署 |
| 2 | 相手の計画との関わり | 町の計画（データヘルス計画など）の課題のうち、事業が関わる項目を表にする。出典のページ番号を脚注に |
| 3 | 判定の基準 | 使った基準値と、それを選んだ理由を【閾値】で書く |
| 4〜 | 結果（目的ごとの節） | 節の区切りページの副題に、何を確かめるかを書く。結果は1ページ1つの主張 |
| | 他地域との比較 | 「参考」と題に付ける。比較の前提（何回目の計測か、何地域か）を【前提】で書く |
| | 住民の声 | アンケートの結果。節の副題は「〇〇に導入したら受けたいか？など生の声を確認」のように問いで書く |
| | 実施結果のまとめ | 実施目的の番号ごとに、結果の数値1つと判断を書く。判断の文末は「〜と判断」「〜と推測」「〜が必要と判断」。ばらつきなどの限界は「但し、〜」で1行添える |
| | 次年度に向けて：お願いとご相談 | お願い・ご相談を ❶❷ で並べ、それぞれに（対象）（目的）（時期）（方策）や（内容）を書く。最後に「以上」 |
| | 【付録】文献 | 発表の中で番号を引いた文献 |
| | 付録（説明者の手持ち） | 発表では見せず、質問が出たときに使うページ。細かい区分の集計、方法の検討など |

### 書き方

- 題は、結果の向きを言葉で書く（「〜に減少」「〜は改善」「2回目は高くなる傾向あり」）。比べたときは相手を題に入れる（「他の自治体に比べ、〜」）。良し悪しが読み取りにくい指標には「低い（良い）」のように添える。
- 語は業務の文書の語にする（抜き出した→抽出、数えた→カウント）。住民は「〜の方」、自社は「弊社」、依頼は「〜させていただけませんか」。案件ごとの呼び名（参加者の群の呼び方など）は、その案件の記憶や CLAUDE.md に従う。
- 図の横の説明は【対象】【結果】【補足】【用語】【前提】で区切り、中の項目は＊や①②で並べる。結論は＜結論＞として最後に置く。
- 内訳は全部示し、合計の割合を添える（「改善〇人・維持〇人・悪化〇人（改善・維持＝〇〇％）」）。
- 範囲（信頼区間）、除外した人数の内訳、方法上の注意（逆の因果の可能性など）は、図の横の説明から脚注か説明者の手持ちへ移す。消さない。まとめのページにも限界を1行残す。

## 社内向けの報告

社内で結果を共有し、判断や次の作業を決めてもらう資料。実例の差分がまだ無いため仮の型で、社内の報告資料の手直しが出たら同じ方法で直す。

### ページの並び

| 順 | ページ | 書くこと |
|---|---|---|
| 1 | 表紙 | 何の報告か、日付、作成者 |
| 2 | 結論と決めてほしいこと | 結論を一文。判断してほしいことがあれば、選択肢と推奨を並べる |
| 3 | 背景 | なぜ調べたか、前回からの経緯。1ページ以内 |
| 4〜 | 結果 | 1ページ1つの主張。題だけを読めば結論の根拠がたどれる順に並べる |
| | 課題・未確定の点 | 分かっていないこと、リスク、確かめる方法 |
| | 次の作業 | 誰が・いつまでに・何をするか |
| | 付録 | 方法、全表、文献 |

### 書き方

- 結論は表紙の次に置く。結果のページは、結論の根拠になる順に並べる。
- 社内の経緯、課題の管理番号、検討中の事情は書いてよい。社外に出す資料に流用するときは消す。
- 方法上の限界は、結果のページの脚注に残す。判断に関わる限界は「課題・未確定の点」に書く。
