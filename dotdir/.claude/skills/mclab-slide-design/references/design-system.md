# MCLab Teal デザイン仕様

この仕様は、膝OAデータ取得計画で作成した白背景・ティール基調の書式を、計画・比較・データ説明用に汎用化したものです。医療固有の数値や条件はテンプレートの規則ではありません。

## 共通設定

| 項目 | 設定 |
| --- | --- |
| 画面 | 16:9、1280 × 720 px、33.867 × 19.05 cm |
| 左右余白 | 52 px、表紙は58〜60 px |
| 標準タイトル | x52、y78、幅1176、高さ54 px |
| タイトル下の線 | x52、y144、幅88、高さ4 px |
| 長いタイトル | 高さ96 px、線はy182、本文はy218以降 |
| 標準本文領域 | x52、y184、幅1176、高さ378 px |
| 結論帯 | x52、y594、幅1176、高さ68 px |
| 脚注 | x52、y674、幅1176、高さ26 px |

幾何値は96 dpiのpxです。PowerPointの文字サイズはptで扱い、1 px = 0.75 ptです。詳細なプレースホルダー位置は `../assets/design-tokens.json` にあります。

| アクセント2 | #1E8C7D | 基本色、表見出し、結論帯 |
| アクセント3 | #01579B | 情報、比較 |
| アクセント4 | #ED6C02 | 注意、検討事項 |
| アクセント5 | #C62828 | 問題、不足、中止 |

補助面色は淡ティール #DDF4F0、淡青 #D8EEF8、淡橙 #FFF0D8、淡緑 #E0F1E1、淡赤 #FDE8E7です。これらの淡色は固定色です。テーマの主要色を大幅に変更した場合は、必要に応じて対応するレイアウトの面色も変更してください。

## 文字

- 日本語はHiragino Sans、英数字はRobotoです。テーマの見出し・本文フォントにも設定されています。フォントファイルは同梱していません。
- 表紙36 pt、標準タイトル25.5 pt、本文16.5〜18 pt、表13.5 pt、脚注9.75 ptが基本です。見出しと数字を太字にします。
- 小さい文字へ縮小する前に、文を短くするかページを分けます。長いタイトルには専用レイアウトを使います。
- 日本語を基本とし、略語・技術用語は必要な場合のみ使います。装飾目的の英語ラベルは追加しません。

## マスターと編集範囲

- 共通マスターは「MCLab 共通マスター」です。
- 「共通ヘッダー_ここに入力すると全ページへ反映」は通常のマスターテキストボックスです。初期状態はゼロ幅文字のみで、画面上は空欄です。固定ブランド名やロゴはありません。
- 共通ヘッダーはPowerPointの［表示］→［スライドマスター］で最上位のマスターを開き、このテキストボックスへ入力します。［選択ウィンドウ］で上記の名前から選べます。
- 自動ページ番号は `slidenum` フィールドです。番号値を通常テキストへ置き換えないでください。
- タイトル・本文・結論・脚注はプレースホルダーです。本文の配置はレイアウトから継承します。フォントと主要色はテーマに連動します。
- 一部の文字サイズ・太字は構成例内に指定しています。全体の文字サイズを変える場合はレイアウトと既存スライドの両方を確認します。
- 表はネイティブ表としてスライド側に置き、対応する表プレースホルダーと関連付けています。表の書式を維持したいときは構成例の表を複製します。新規挿入した表は、必ずしも独自書式が自動適用されるわけではありません。

## 表の書式

見出しはアクセント2の背景と白太字。本文は白と背景2の交互行、0.8 pxの細い全面罫線を使用します。セル余白は左右12 px、上下6 px、上下中央が基本です。

ラベル列は左揃え、数値列は中央揃え。先頭列も数値の場合は、他の数値列と揃えます。状態の強調には文字色と淡色の塗りを併用します。結合セルを必要以上に増やさず、スクリーンショットやテキストボックスの寄せ集めに置き換えません。

## 再利用時の確認

構成例の数値は架空です。新しい資料に残さず、ユーザーの入力または確認した出典へ置き換えます。出典や条件は脚注またはノートに記録します。

既存レイアウトを選び、プレースホルダーの種類とindexを保って編集します。スライド単位で枠を描き直すより、該当する構成例の複製を優先します。表の行数が増える場合は、列幅・行高を再調整して全ページを再表示します。
