# スライドの AI らしさ点検表

出典：[Dragoon0x/useslidekit](https://github.com/Dragoon0x/useslidekit) の `references/ANTI-SLOP.md`（commit `3e371a0`、MIT License, Copyright (c) 2026 Dragoon0x。許諾文の全文は `slide-slop-checklist.LICENSE`）。研究発表と MCLab の型に合う項目を選んで日本語にし、スタイルガイドに記録済みの指摘と storytelling-with-data の規則を加えた。取得元の更新は `make skills-check` で確かめる（`.bin/skills-upstream.json` の `useslidekit-anti-slop`）。

描画確認（`render-check.sh`）の後、全ページの画像をこの表と照らし合わせる。ただし `report-patterns.md` の型どおりに置くページ（表紙、節の区切り、実施結果のまとめ、お願いとご相談など）は、「題が話題の名前だけ」と「箇条書きが5つ以上」の対象外とする。該当した項目は直してから報告する。該当が多いときは、ページ単位で直すより、題だけを並べた筋書きから作り直す。

## 中身

| 該当する状態 | 直し方 |
|---|---|
| 題が話題の名前だけ（「結果」「歩行速度」「今後の課題」） | 主張を書く（「歩行速度が3年後の新規フレイル発症を予測」） |
| 題が「だった」「である」「した」で終わる文（英語の題の直訳調） | 主張は残し、文末を名詞か数値で止める（「〜は最も速い群の約4倍」） |
| 題がメタな文（「〜を整理します」「〜について」「〜の概要」） | そのページで言いたいことを書く |
| 「ポイントは3つ」のように項目の数を宣言する | 数を言わず、中身を並べる |
| 項目の数がどのページも同じ（箇条書き3つずつ、カード3枚ずつ） | 数は内容で決める。そろえるために足したり削ったりしない |
| 箇条書き1つが段落になっている | 1行に1つの事実。説明が要るなら本文の文章にする |
| 1ページの箇条書きが5つ以上 | ページを分けるか、表にする |
| 中身のない言葉（「革新的」「包括的」「活用」「最適化」「シナジー」） | 数値・対象・期間など、確かめられる事実に置き換える |
| 根拠のない強調（「極めて重要」「大きな成果」）、壮大な締め | 根拠の数値を添えるか、削る |
| 前のページを言い直しただけのページ | 削る。どのページも新しい情報を1つ足す |
| まとめのページが本文の繰り返し | 判断・決めてほしいこと・次の行動を書く |

## 構成

| 該当する状態 | 直し方 |
|---|---|
| 社外への報告が分析の結果の羅列で終わり、相手の目的との対応や次のお願いがない | `report-patterns.md` の自治体向けの型で、目的の明示・まとめ・お願いとご相談を足す |
| 全ページが同じ型（カード並べ、2列比較の連続） | 内容に合う型を選ぶ。3列比較は比べる案が実際に3つあるときだけ |
| 題だけを順に読むと話がつながらない | 題の並びで筋が通るまで、順番と題を直す |
| どのページも同じ密度 | 主張1つと図1つの軽いページと、詳細の表のページを混ぜる |
| 意味のない区切りページ、10枚未満の資料の目次 | 話題が変わるときだけ区切る。短い資料に目次は置かない |
| 発表時間に対して枚数が多い | 口頭発表は1分1枚を上限の目安にする |
| 付録が本編より長い | 詳細は付録を5〜10枚に絞り、残りは別資料にする |

## 図と数値

| 該当する状態 | 直し方 |
|---|---|
| 円グラフ、3D、二重の縦軸 | 横棒グラフにする。二重の縦軸は2つの図に分ける |
| 系列が多く、全部が色付き | 主張に関わる1〜2本だけを強調色にし、残りは灰色にする |
| 図に注釈がない | 読み取ってほしい点を図の中に短く書く |
| 凡例が図から離れている | 線や棒の横に直接名前を書く |
| 表が20行以上 | 主張に関わる行に絞り、全表は付録にする |
| 数値に人数・比較の相手・単位がない | 「n=120」「対照群との差」「秒」などを添える |
| 小数の桁が多すぎる（23.47%） | 判断に要る桁で丸める |

## 見た目

テンプレートにない装飾（アイコン、絵文字、影、グラデーション、角の飾り図形）を足さない。色・文字・余白はテンプレートのまま使う。
