# Humanize（AI 臭の書き換え）

stop-ai-slop の辞書（`~/.claude/skills/stop-ai-slop/references/`）を使い、AI 臭パターンに該当する箇所だけを最小修正で書き換える。目的は「人間の読者が感じる AI 臭の除去」であり、AI 検出器を欺くことではない（実測で不可能と確認されている。stop-ai-slop の宣言を参照）。

## 鉄則（優先順）

1. **声の保存**：文体（です/ます・だ/である）、一人称、レジスター（学術・ビジネス・カジュアル）は原文のまま。AI 臭の除去と文体変更は別の作業
2. **事実保全**：数値・固有名詞・日付・引用・主張の強さは改変禁止。"This study" を "This article" に変える類のジャンル書き換えも禁止。ヘッジ表現（J11・J15〜J17）の除去は言い回しの整理に留め、断定度と出典の帰属は原文の水準を保つ。辞書の推奨対応と鉄則が衝突したら鉄則を優先する
3. **最小修正**：辞書パターンに該当する箇所だけ直す。全体の文字数増減は ±30% 以内を目安。全面改稿はユーザーが明示的に求めたときのみ
4. **削りすぎ防止**：素っ気なさ自体も AI 臭。具体例・温度・文のつなぎは残す（必要なら足す）

## フロー（2パス）

### Step 0: 声の把握
原文の文体・一人称・レジスターを1行でメモしてから着手する（例：「です/ます体・一人称なし・一般向け解説」）。このメモが Step 2 の照合基準になる。

### Step 1: パス1（辞書照合修正）
- 言語に応じて patterns-ja.md / patterns-en.md を読む（混在文書は両方）
- 該当パターンを「推奨対応」に従って修正する。⚠ 印（検出専用）のパターンには偽装対応しない

### Step 2: パス2（自己監査）
修正後の全文を読み直して確認する：
- まだ AI 臭い箇所はないか（辞書外の新種も含めて自問する）
- Step 0 のメモと声が一致しているか（文体・レジスターが変わっていたら差し戻す）
- 数値・固有名詞・主張の強さが無傷か
- 数値制約：同一語尾の連続は2文まで／日本語文中の em dash は0本／英語の em dash は約300語に1本／太字は1セクション1〜2箇所／400字（英語150語）に1つは短い文を置く

### Step 3: 出力
1. 書き換え後の全文
2. **何を変えたか**：パターン ID 付きの変更一覧
3. **変えなかったもの**：保存した文体・事実を1〜2行で明記
4. 辞書にない AI 臭を見つけたら「新種候補」として報告する（辞書への追記は stop-ai-slop の育成フローに従い、ユーザー承認後に行う）

## よくある失敗

| 失敗 | 現実 |
|------|------|
| です/ます体をだ/である体に変えてしまう | 文体は AI 臭ではない。原文の声を保存する |
| 学術英語の robust / significant を機械的に削る | 統計・専門用語として正当なら残す。密度で判断する |
| 短く削りすぎて素っ気なくなる | 素っ気なさも AI 臭。±30% の目安を守る |
| 数値や断定の強さを「ついでに」調整する | 事実と主張の強さは不可侵。表現だけを変える |
| J11・J17 の修正で断定に格上げしてしまう | ヘッジ除去は表現の整理。「多くの研究が示す〜ではないでしょうか」→「研究では〜が目安とされる」のように、帰属と断定度を保って直す |
| 全面的に書き直してしまう | 該当箇所だけ。原文の癖は書き手の個性として残す |
