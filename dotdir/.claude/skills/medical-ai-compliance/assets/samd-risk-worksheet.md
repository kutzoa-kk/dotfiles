# SaMD リスク分類 判定ワークシート

IMDRF N12（IMDRF/SAWG/N12FINAL:2014）に基づく 2 軸判定ワークシートです。  
本ワークシートを使い、対象 SaMD を **Category I〜IV** に分類してください。

> ⚠️ **前提注記（重要）**: 本ワークシートのマトリクスは、IMDRF N12FINAL:2014 PDF の  
> 条文を直接抽出したものではなく、二次的解説資料に基づいています。  
> 各セルの正確な値・定義・根拠条文は、一次情報（N12FINAL:2014 PDF）で必ず確認してください。  
> URL: https://www.imdrf.org/documents/software-medical-device-possible-framework-risk-categorization-and-corresponding-considerations

---

## 使い方

1. **ステップ 1** — 対象 SaMD が使われる医療状況の重大性を 1 つ選ぶ
2. **ステップ 2** — SaMD が提供する情報の重要性を 1 つ選ぶ
3. **ステップ 3** — マトリクスで Category（I〜IV）を特定する
4. **ステップ 4** — 薬機法クラスとの関係を確認する（重要）
5. **ステップ 5** — 判定結果に応じた次アクションを計画する

## ステップ 1: 医療状況の重大性を選択（軸 1）

**軸 1: State of Healthcare Situation（医療状況の重大性）**

> ⚠️ **未確認注記**: 以下の各区分の定義文言は参考訳です。正確な条文は N12FINAL:2014 PDF を参照してください。

以下の 3 区分から対象 SaMD が使われる状況に最も該当するものを 1 つ選んでください。

---

**区分A — Critical（重大）**

生命を脅かす疾患・状態。迅速な介入が必要な状況。

例: 急性心筋梗塞、脳卒中、敗血症、重篤なアレルギー反応

```
[ ] 選択する → 軸 1 = Critical
```

---

**区分B — Serious（重篤）**

生命を脅かす可能性があるが、Critical ほど即時介入を要しない状態。

例: 慢性疾患の急性増悪、悪性腫瘍の診断・管理

```
[ ] 選択する → 軸 1 = Serious
```

---

**区分C — Non-serious（非重篤）**

Critical・Serious のいずれにも該当しない状態。

例: 軽微な症状管理、予防・ウェルネス目的

```
[ ] 選択する → 軸 1 = Non-serious
```

## ステップ 2: 情報の重要性を選択（軸 2）

**軸 2: Significance of Information Provided by SaMD（SaMD が提供する情報の重要性）**

> ⚠️ **未確認注記**: 以下の区分文言は参考訳です。正確な条文は N12FINAL:2014 PDF を参照してください。

以下の 3 区分から対象 SaMD が提供する情報の性質に最も該当するものを 1 つ選んでください。

---

**区分X — Treat or diagnose（治療・診断）**

SaMD の出力（診断結果・治療推奨等）が、患者の治療または診断の決定に直接使用される。

例: 自動診断・病変検出・治療方針決定ツール

```
[ ] 選択する → 軸 2 = Treat or diagnose
```

---

**区分Y — Drive clinical management（臨床管理を主導）**

SaMD の出力が、臨床管理の意思決定を主導・駆動する。診断や治療の最終決定ではないが、臨床フローを強く方向づける。

例: 優先度トリアージ、治療プロトコル選択支援

```
[ ] 選択する → 軸 2 = Drive clinical management
```

---

**区分Z — Inform clinical management（臨床管理を補助）**

SaMD の出力が、臨床判断の参考情報として利用される。最終判断は臨床家が行う。

例: 患者データ可視化、リスクスコア表示、傾向分析

```
[ ] 選択する → 軸 2 = Inform clinical management
```

---

**ステップ 2 記入欄**

```
選択した区分 : [ ] Treat or diagnose
               [ ] Drive clinical management
               [ ] Inform clinical management
選択理由メモ : ___________________________________________________
```

## ステップ 3: リスク分類マトリクスで Category を判定

ステップ 1・2 の選択結果を組み合わせて、下表から Category を読み取ってください。

**IMDRF N12 リスク分類マトリクス（Category I〜IV）**

> ⚠️ **未確認注記**: 下表のセル値は二次的解説資料に基づきます。  
> N12FINAL:2014 PDF の本文・Appendix の Table で正確な値を確認してください。  
> 本スキル内の `references/regulatory-standards.md` のマトリクスとも一致します（両者とも IMDRF N12 の標準的なカテゴリ配置）。各セルの定義文言・境界条件は上記 N12 PDF で最終確認してください。

Category I が **最低リスク**、Category IV が **最高リスク** です。

| 情報の重要性（軸 2）↓ / 医療状況の重大性（軸 1）→ | **Critical** | **Serious** | **Non-serious** |
|----------------------------------------------------|:------------:|:-----------:|:---------------:|
| **Treat or diagnose**                              | **IV**       | **III**     | **II**          |
| **Drive clinical management**                      | **III**      | **II**      | **I**           |
| **Inform clinical management**                     | **II**       | **I**       | **I**           |

### カテゴリ別リスクレベル概要

| Category | リスクレベル | 規制対応の一般的方向性（概要） |
|----------|--------------|-------------------------------|
| **I**    | 最低         | 多くの国で軽微な規制           |
| **II**   | 低〜中       | 一般的な規制要件               |
| **III**  | 中〜高       | 強化された規制要件             |
| **IV**   | 最高         | 最も厳格な規制要件             |

> ⚠️ 各国の具体的な規制要件の対応は、各国当局の判断に依存します。  
> N12FINAL:2014 および各国の実施文書を参照してください。

## ステップ 4: 薬機法クラスとの関係（重要な注意）

### IMDRF Category と薬機法クラス（I〜IV）は 1 対 1 に対応しません

IMDRF N12 の Category I〜IV と日本の薬機法（医薬品医療機器等法）のクラス分類 I〜IV は、  
**単純な 1 対 1 の対応関係にありません。**

- IMDRF N12 は国際的なリスク分類の「枠組み」であり、各国の薬事規制への適用方法は国・当局によって異なります。
- 日本の薬機法クラス（クラス I〜IV）は、PMDA（薬事・食品衛生審議会の審議を含む）による該当性判断と相談を経て確定します。
- IMDRF Category を日本の薬機法クラスに機械的に読み替えることは推奨されません。

**薬機法上の分類・該当性の確定方法**

```
1. PMDA 事前面談・相談申請（医療機器該当性確認を含む）
2. 薬機法クラス分類の確認（クラス I〜IV）
3. 第三者認証 / 承認申請区分の判断
```

薬機法クラス分類の詳細は `references/japan-regulatory.md` を参照してください。

> 📌 **アクション**: 薬機法上のクラス・承認区分が不明な場合は、  
> **PMDA への事前相談（医療機器戦略相談等）** を早期に実施することを強く推奨します。  
> URL: https://www.pmda.go.jp/review-services/drug-reviews/review-information/devices/0005.html

## ステップ 5: 判定結果に応じた次アクション

判定した Category を参考に、以下の対応事項を計画してください。

### 全 Category 共通

| 対応事項 | 参照規格 / 文書 |
|----------|----------------|
| リスクマネジメント計画の策定 | ISO 14971:2019 |
| ソフトウェアライフサイクルプロセスの確立 | IEC 62304:2006+AMD1:2015 |
| QMS の構築（または既存 QMS への統合） | ISO 13485:2016 |
| 日本向け薬機法クラス・承認区分の確認 | PMDA 相談・`references/japan-regulatory.md` |

### Category III / IV 特有の追加検討事項

| 対応事項 | 参照規格 / 文書 |
|----------|----------------|
| IEC 62304 ソフトウェア安全クラス C 相当の要件適用 | IEC 62304 §4.3 |
| 詳細設計文書・単体テスト・双方向トレーサビリティの確保 | IEC 62304 |
| ベネフィット・リスク分析の文書化 | ISO 14971:2019 §9 |
| AI/ML 固有リスク（データドリフト・バイアス）の特定 | ISO/IEC 42001:2023, ISO 14971 |
| 市販後監視（PMS）計画の強化 | ISO 14971:2019 §10, 薬機法 |

### AI / ML を使用する SaMD の追加検討事項

| 対応事項 | 参照規格 / 文書 |
|----------|----------------|
| 学習データガバナンス（品質・代表性・偏り） | ISO/IEC 42001:2023 |
| モデル性能の継続的評価・ドリフト検知 | ISO/IEC 42001:2023 |
| 説明可能性（Explainability）の担保 | ISO/IEC 42001:2023 |
| ヘルスソフトウェア製品安全要件 | IEC 82304-1:2016 |
