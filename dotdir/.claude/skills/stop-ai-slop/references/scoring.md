# AI 臭採点基準（scoring）

5次元×10点、合計50点。採点は目安であり、根拠は必ずパターン ID の指摘件数と引用で示す（点数だけの報告はしない）。

| 次元 | 満点の状態 | 主な減点パターン |
|------|-----------|----------------|
| 直接性 | 前置き・フィラー・ヘッジなしで本題に入る | J01 J02 J11 J15 J16 E08 E10 |
| リズム | 文長・語尾に自然な変化がある | J09 J10 J14 E12 E13 |
| 具体性 | 抽象万能語でなく具体語・数字で書かれている | J26 J27 J28 J29 E01 E02 E04 |
| 読者信頼 | 構造宣言・過剰説明・ヨイショで読者を子ども扱いしない | J03 J04 J05 J12 J13 E06 E11 |
| 人間らしさ | 記号・書式・定型句の機械的な癖がない | J18〜J25 E03 E05 E07 E09 E14 |

## 減点の目安

- 各次元 10 点から開始。該当パターン1種につき −2、同一パターンの頻発（3箇所以上）は −4
- 下限は 0 点。他次元へ重複減点しない（最も近い次元でのみ減点）

## 判定

| 合計 | 判定 |
|------|------|
| 40〜50 | 合格。指摘のみ報告 |
| 30〜39 | 部分修正を推奨（該当箇所だけ humanize-ja で直す） |
| 〜29 | humanize-ja での書き換えを推奨 |

## 強シグナル（点数に関係なく1件で要対応）

- E15 AI 痕跡文字列（oaicite 等）
- E16 引用の破綻（無効な DOI 等）
- J05「いかがでしたか」型まとめ
- J18 日本語文中の em dash
